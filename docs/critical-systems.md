# 关键系统清单与 RTO 目标（M1 沙盒）

M1 跑在单机沙盒上，下面的时间是设计目标，不是已经演练过的生产指标。

| 系统 | 作用 | RPO | RTO 目标 |
|---|---|---|---|
| 撮合引擎 | XAU/USD 订单簿，单线程，命令写入日志后再改内存 | 0（每条命令先落入日志；`ENGINE_FSYNC_EVERY` 控制刷盘频率） | 进程重启后重放日志。可用区故障目标 < 5 分钟；区域灾难目标 < 2 小时。监管口径底线 4 小时。 |
| 账本 | PostgreSQL 复式记账 | 跟随数据库同步提交 | 与数据库恢复点一致。沙盒为单实例。 |
| 网关 | 认证、KYC、下单、行情推送 | 无独立状态，订单结果以引擎日志和账本为准 | 无状态，可直接重启。 |
| 审计 | 引擎日志 + 账本分录 | 日志与分录都保留 | 生产目标是哈希链与 WORM，保存不少于 5 年。M1 尚未接入对象锁。 |

启动时网关会把仍处于 `pending` 的冻结单和引擎日志对上：引擎没有这张单就解冻，有则按成交结果补记账。

市场暂停后，新单被拒绝，撤单仍然允许。
