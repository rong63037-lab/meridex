# 计量单位

撮合与账本全程使用整数，不使用浮点。

| 量 | 单位 | 说明 |
|---|---|---|
| 黄金数量 | 毫克 `mg` | 1 克 = 1,000 mg。界面按克显示，最多三位小数。 |
| 价格 | 美分 / 克 | 最小变动 1 美分（0.01 美元/克）。 |
| 美元 | 微美元 `µUSD` | 1 美元 = 1,000,000 µUSD。 |
| 成交金额 | µUSD | `金额 = 数量_mg × 价格_美分每克 × 10` |

例：1.000 克、130.00 美元/克 → 1,000 × 13,000 × 10 = 130,000,000 µUSD = 130.00 美元。

金衡盎司仅用于界面换算（1 金衡盎司 ≈ 31.1034768 克），不进入撮合，也不进入账本。这样货银对付不会出现盎司换算的余数。

参考价默认 13,000 美分/克（130.00 美元/克）。价格带 ±500 bps，熔断带 ±200 bps。限价超出价格带会被拒绝。若成交价将越过熔断带，该笔不成交，市场暂停，直到合规官恢复。
